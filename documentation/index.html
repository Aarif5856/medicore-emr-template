1. Introduction

Thank you for purchasing MediCore EMR! 🎉

MediCore is a modern, production-ready Medical EMR (Electronic Medical Records) admin dashboard template built with React 19, Tailwind CSS v4, shadcn/ui, and TypeScript. It provides a complete frontend foundation for clinics, hospitals, telemedicine platforms, and healthcare SaaS products.

This documentation walks you through installation, project structure, theming, replacing the sample data with your own API, and common customizations. No advanced React knowledge is required to get started — every step is explained for beginners.

2. Requirements

  • Node.js 18 or newer (Node 20+ recommended) — download from https://nodejs.org
  • npm (comes with Node.js) or bun (optional, faster)
  • A code editor such as VS Code
  • Basic familiarity with React is helpful but not required for simple text/color changes

3. Installation

Step 1 — Extract the files

Unzip the download package. Open the source folder in your code editor or terminal.

Step 2 — Install dependencies

cd source
npm install

Or, if you prefer bun (a bun.lock file is included):

bun install

Step 3 — Start the development server

npm run dev

Open the local URL shown in your terminal (typically http://localhost:8080 or http://localhost:5173). You should see the MediCore dashboard running with sample data.

Tip: If npm install reports peer-dependency warnings, they are safe to ignore. If installation fails, delete the node_modules folder and the lock file, then run npm install again.

4. Build for Production

npm run build

This creates an optimized production build. To preview the production build locally:

npm run preview

MediCore uses TanStack Router with file-based routing. Every file in src/routes/ automatically becomes a page:

To add a new page: create a file such as src/routes/_app.reports.tsx, export a component, and add a link to it in src/components/app-sidebar.tsx. The route is generated automatically.

7. Theming (Light / Dark Mode)

Theme switching is handled by the use-theme hook (src/hooks/use-theme.tsx). The toggle button in the header switches between light and dark instantly.

Changing brand colors

All colors are defined as design tokens in src/styles.css using Tailwind CSS v4's @theme / CSS-variable system. Light-mode tokens are defined in :root and dark-mode overrides under the .dark selector. For example, to change the primary accent color, edit the --primary variable in both places. Every component updates automatically because they all reference the same tokens.

Note: Tailwind CSS v4 does not use tailwind.config.js. Theme customization lives directly in src/styles.css — this is the modern v4 approach.

8. Sample Data & Connecting Your API

All demo content (patients, doctors, appointments, lab tests, medicines, invoices, staff, messages, notifications, dashboard stats) lives in plain TypeScript files inside src/data/. Each file exports typed arrays/objects, so you can see the exact shape your API should return.

Replacing sample data with a real backend

  1. Open the relevant data file, e.g. src/data/patients.ts, and note the exported type/interface.
  2. The template already includes TanStack Query. Replace the local import with a query that fetches from your API and returns data in the same shape:
import { useQuery } from "@tanstack/react-query";

const { data: patients, isLoading } = useQuery({
  queryKey: ["patients"],
  queryFn: () => fetch("/api/patients").then(r => r.json()),
});
  1. Loading skeletons (table-skeleton.tsx, skeleton.tsx) and empty/error states (empty-state.tsx, error-state.tsx) are already built — wire them to isLoading / isError.
Important: MediCore is a frontend template. It does not include a backend, database, or real authentication. The login page is UI-only — connect it to your own auth provider (Supabase, Firebase, your REST API, etc.).

9. UI Components

The template ships with 45+ reusable components in src/components/ui/, based on shadcn/ui (Radix UI primitives + Tailwind). Highlights:

  • Data display: table, card, badge, avatar, chart (Recharts wrapper), progress, mini-stat-card
  • Overlays: dialog, alert-dialog, sheet, drawer, popover, tooltip, hover-card, dropdown-menu
  • Forms: input, textarea, select, checkbox, radio-group, switch, slider, form (react-hook-form + zod), calendar / date picker, input-otp
  • Navigation: sidebar, tabs, breadcrumb, pagination, command palette (Cmd/Ctrl + K global search), menubar
  • Feedback: sonner toasts, skeleton loaders, empty-state, error-state

Because these are standard shadcn/ui components, you can copy any new component from the shadcn/ui documentation and it will match the design system automatically.

10. Common Customizations

Change the logo & brand name

  • Logo mark: src/components/brand/logo-mark.tsx
  • Sidebar brand text: src/components/app-sidebar.tsx
  • Favicon: public/favicon.svg

Edit sidebar menu items

Open src/components/app-sidebar.tsx — menu sections (Main, Clinical, Finance, Management, System) are defined as simple arrays. Add, remove, or rename items there.

Change currency / date formats

Amounts and dates are rendered where they are displayed (tables, cards). Dates use date-fns — adjust format strings, e.g. format(date, "MMM d, yyyy").

Export to CSV

The Export buttons use src/lib/export-csv.ts. It converts the current table data to a downloadable CSV — reuse it for any new table.

11. Deployment

Netlify (recommended — config included)

A ready-made netlify.toml is included. Push the project to a Git repository, connect it in Netlify, and it will detect the build settings automatically. Or drag-and-drop: run npm run build and upload the output folder.

Vercel

Import the repository in Vercel and select the Vite framework preset. Build command npm run build.

12. FAQ

Is a backend or database included?

No. MediCore is a frontend template with realistic local sample data, designed to plug into any backend.

Does it work with npm, yarn, and bun?

Yes. A bun.lock is included, but npm install works normally.

Can I use it for client projects?

Yes — per the marketplace license you purchased. For multiple end products, purchase the appropriate license per project.

Is it responsive?

Yes — every page is fully responsive across desktop, tablet, and mobile, including a mobile drawer sidebar.

How do I update the sample data?

Edit the TypeScript files in src/data/. Changes appear instantly with hot reload.
