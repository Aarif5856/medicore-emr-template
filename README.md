# MediCore EMR — Medical Admin Dashboard Template

Modern Medical EMR admin dashboard built with **React 19, Tailwind CSS v4, shadcn/ui, TanStack Router, and TypeScript**.

> 📖 **Full documentation:** open `documentation/index.html` in your browser.

## Quick Start

```bash
cd source
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Build

```bash
npm run build
npm run preview
```

## What's Inside

- 14 pages: Dashboard, Patients, Patient Profile, Doctors, Appointments (calendar + list), Laboratory, Pharmacy, Billing & Invoices, Staff, Messages, Notifications, Settings, Login
- Light + Dark mode, fully responsive
- 45+ reusable shadcn/ui components
- Sample data in `src/data/` — replace with your API (TanStack Query included)

## Requirements

- Node.js 18+ (20+ recommended)
